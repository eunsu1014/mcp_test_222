# MCP Test Project

이 프로젝트는 MCP(Multi-Channel Platform) 통합 테스트를 위한 레포지토리입니다.

## 프로젝트 개요

이 레포지토리는 다음과 같은 목적으로 생성되었습니다:
- MCP 기능 테스트
- GitHub API 통합 테스트
- 자동화된 워크플로우 테스트

## 기술 스택

- Python
- GitHub API
- MCP Integration

## 시작하기

1. 레포지토리 클론
```bash
git clone https://github.com/eunsu1014/mcp_test_222.git
```

2. 의존성 설치
```bash
pip install -r requirements.txt
```
